Primeira atividade em grupo da LASI, para treinar a capacidade de criar codigos e ultilizar o github para versionamento de programas futuros.
Meu código tem a função de ser uma agenda de contatos simples, com as funções de:
* adicionar contatos
* buscar contatos
* editar contatos
* remover contatos
* listar contatos 




Foram separados essas funções e depois juntadas todas em um swtich para ser o menu principal desse programa.
E foi usado uma struct para os dados dos contatos, visto que é mais fácil guardar dados diferentes assim, sendo os dados nome e telefone guardados em formato char.
O maximo de contatos pode ser escolhido dentro do codigo principal no define MAX-CONTATOS
além das funções de contatos, também implementei funções para organizar o programa, como limpar o terminal e função de confirmar ações para limpar só após a confirmação e também uma função para salvar os contatos em um arquivo e depois carregar para manter os contatos salvos mesmo depois de finalizar o programa
